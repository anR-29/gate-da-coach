# Data interpretation

## Core ideas
- Percent change $= \dfrac{\text{new} - \text{old}}{\text{old}} \times 100$; the base is the **earlier** (or "compared against") value.
- "A exceeds B by x%" uses B as base; "A is x% of B" is a different number (200% of = 100% more).
- Weighted mean $= \sum w_i x_i / \sum w_i$; a plain mean of group means is wrong when sizes differ.
- Shares: if an amount is fixed and the total grows by $g$, new share = old share / $(1+g)$.
- Largest absolute change ≠ largest percentage change.
- A new value that sets a new average: value = new mean × new n − old sum.
- Derived quantities (profit = revenue − cost) must be computed before taking % change.
- Read labels and units on the chart; don't eyeball bar heights when values are printed.

## Shortcuts
| Need | Do |
|---|---|
| Compare % growth | compute ratios new/old only |
| Share of total | sum the total once, reuse it |
| Many weighted terms | use deviations from a round number |
| Estimate | round, but check whether the answer options are close |

## Traps
1. **Wrong base** (divided by the new value). Fix: write "base = ..." before dividing.
2. **Absolute change reported as %.** Fix: the answer has a % sign only after dividing.
3. **Unweighted mean of group means.** Fix: multiply by counts first.
4. **Largest bar change picked** when it was a decrease, or the largest absolute change. Fix: compute signed % for each.
5. **Ratio part reported instead of total** (new Sales count vs firm total). Fix: re-read what the question totals.
6. **Arithmetic drift in estimation** (36/200 called "about 20%"). Fix: if options straddle a threshold, compute exactly.
7. **Share assumed constant** when only the total changed. Fix: fixed amount ÷ new total.
8. **Mixed bases** across items. Fix: same base (old value) for every item.

## Recall
- % change = (new − old)/old.
- "x% more than B": base B; "x% of B": ratio.
- Weighted mean = Σwx / Σw.
- New share = fixed amount / new total.
- Added value = new mean × new n − old sum.
- Absolute rise ≠ percentage rise.

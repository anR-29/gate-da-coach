# Numerical ability

## Core ideas
- Ratio $a:b$ with total $T$: one part $= T/(a+b)$. Write down **which quantity is asked** (a part, the total, the change).
- Mixtures: the component you do not add stays fixed; set up the new ratio on it.
- Alligation: weak : strong $= (S - M) : (M - W)$ for mean $M$.
- Successive % changes: multiply factors, $(1+p)(1+q)$; +20% then −20% is −4%.
- Digits of $N$: $\lfloor \log_{10} N \rfloor + 1$. $\log_b 1 = 0$, $\log_b b^k = k$, $\log_b (1/x) = -\log_b x$.
- Averages: work with **sums** ($n \times$ mean), never subtract averages directly.
- Work: add **rates** ($1/a + 1/b$), not days.
- Probability with dice/coins: count **ordered** outcomes; sums are not equally likely.
- Compound growth: $(1+r)^n$; rule of 72 is an estimate, check the integer year.

## Shortcuts
| Task | Shortcut |
|---|---|
| Doubling at r% | about $72/r$ years, then verify |
| Estimation | round to 1–2 significant figures, track powers of 10 |
| Removed value | old sum − new sum |
| Revenue after price cut c | need quantity factor $> 1/(1-c)$ |

## Traps
1. **Part reported instead of total** (boys instead of class size; valid votes instead of list). Fix: underline the noun after "how many".
2. **Final amount reported instead of amount added.** Fix: answer = new − old.
3. **Inverted ratio** (3 : 2 read as water : milk). Fix: write labels on every ratio.
4. **Arithmetic drift in estimation** (decimal place lost). Fix: write each number as $a \times 10^k$.
5. **Adding percentages** (+20 −20 = 0). Fix: multiply factors.
6. **floor(log) as digit count.** Fix: add 1.
7. **Unordered outcomes treated as equally likely.** Fix: list ordered pairs out of 36.
8. **Off-by-one in growth years.** Fix: compute $(1+r)^n$ for the two candidate n.

## Recall
- One part = total ÷ sum of ratio terms.
- Alligation: weak : strong = (S − M) : (M − W).
- Successive change: multiply $(1 \pm p)$.
- Digits = floor(log₁₀ N) + 1.
- Work: rates add; time = 1 / rate.
- Removed number = n·old mean − (n−1)·new mean.
- P(sum 7) = 6/36, P(sum 8) = 5/36.
- 1.1⁷ ≈ 1.95, 1.1⁸ ≈ 2.14.

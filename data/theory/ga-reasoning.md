# Analytical and logical reasoning

## Core ideas
- $P \to Q$ is equivalent only to its **contrapositive** $\neg Q \to \neg P$. Converse $Q \to P$ and inverse $\neg P \to \neg Q$ do not follow.
- "A unless B" = "if not B then A". "Not A unless B" = "if not B then not A" = "if A then B".
- Syllogisms: draw Venn circles; a conclusion follows only if it holds in **every** possible drawing.
- "Some A are B" ⇔ "Some B are A". "No A is B" ⇔ "No B is A". "All A are B" does **not** give "All B are A".
- Seating/ordering: fix the absolute clues first (ends, middle), then relative ones; note facing direction (left/right flip when facing south).
- Series: check differences, ratios, alternating terms, squares/cubes ± 1, factorials; letters → positions 1–26, wrap with 26.
- Data sufficiency: test each statement alone, then together; one counterexample kills sufficiency.
- Directions: track (x, y) coordinates; right turn from north = east.

## Shortcuts
| Statement | Safe rewrite |
|---|---|
| A unless B | ¬B → A |
| Not A unless B | A → B |
| Only if B, A | A → B |
| No A is B; some C are A | some C are not B |

## Traps
1. **Inverse chosen instead of contrapositive for "unless".** Fix: rewrite as if-then, then negate **and** swap.
2. **Converse accepted** (approval → restart). Fix: a necessary condition is not sufficient.
3. **Possibility treated as certainty** in syllogisms. Fix: draw one diagram where the conclusion fails.
4. **"Some" upgraded to "all/no".** Fix: only the overlap is constrained.
5. **Counting from the wrong end** in seating. Fix: number seats 1…n from the left before answering.
6. **Repeating the last gap** in a series. Fix: look at the gaps of the gaps.
7. **Wrap-around off by one** in letter series. Fix: A = 1, Z = 26; subtract 26.
8. **Missing the negative root** in sufficiency ($x^2 = 16$). Fix: list all values.
9. **Adding path lengths** for displacement. Fix: use net (x, y) and Pythagoras.

## Recall
- P → Q ≡ ¬Q → ¬P only.
- A unless B ≡ ¬B → A.
- Not A unless B ≡ A → B.
- Some A are B ⇔ some B are A.
- No A is B + some C are A ⇒ some C are not B.
- Letters: A = 1 … Z = 26, wrap by −26.
- Data sufficiency: alone, alone, together.

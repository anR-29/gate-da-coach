# Reading comprehension and inference

## Core ideas
- Read the **question word first**: supported / inferred / NOT supported / goes beyond / main idea / reason.
- "Supported" = stated or follows necessarily. "Goes beyond" = adds a claim, group, cause or comparison the passage never makes.
- For every option, point to the sentence that backs it. No sentence → beyond the passage.
- Track **direction**: who acts on whom (X drives Y vs Y drives X).
- Track **qualifiers**: not, only, some, most, main, partly, may. One changed qualifier flips an option.
- Main idea = what every paragraph supports; a true detail is not the main idea.
- Reason questions: match the reason to the **right** change (the passage may give reasons for two changes).
- "Must hold" = necessary condition; a stronger condition (sufficient) is a trap.

## Shortcuts
| Question type | Correct option usually | Wrong options usually |
|---|---|---|
| Supported | a paraphrase with the same qualifiers | overgeneralise, reverse, add a cause |
| NOT / beyond | the one with no backing sentence | three restated facts |
| Main idea | broad and covers all parts | one detail, or an outside comparison |
| Study design | "cannot yet show causation" | "proves X causes Y" |

## Traps
1. **Reversed subject–object** (birds control crabs when crabs drive birds). Fix: write the arrow X → Y from the passage before reading options.
2. **Supported option picked on a "goes beyond"/NOT question.** Fix: circle NOT/beyond; a restated fact is the *wrong* answer there.
3. **"not randomised" read as "randomised".** Fix: underline every *not*; non-random groups → no causal claim.
4. **Overgeneralising** "main food in breeding season" to "only food all year". Fix: compare quantifiers word for word.
5. **Detail chosen as main idea.** Fix: ask "does this cover the whole passage?"
6. **Reason for the wrong change.** Fix: link each reason to its own sentence.
7. **Sufficient vs necessary** (doubling vs >25% rise). Fix: for "must", find the weakest condition that still works.

## Recall
- Read the question stem before the passage.
- Every correct option has a backing sentence.
- Arrow direction: X → Y; never accept Y → X.
- NOT/beyond: three options are true restatements.
- not randomised / self-selected → association only.
- Main idea ≠ true detail.
- Must = necessary, not sufficient.

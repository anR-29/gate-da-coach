# Grammar, vocabulary and usage

## Core ideas
- Read the **whole** sentence before looking at options; the clue word (although, but, without, by) usually decides the blank.
- Articles go by **sound**, not spelling: *an hour, an honest, an MBA* but *a useful, a European, a one-day*.
- *for* + duration (for six years); *since* + point in time (since 2019). "By + future time" → future perfect (*will have worked*).
- Confusables: *assure* a person; *ensure* an outcome; *insure* against loss. *affect* (verb) / *effect* (noun).
- Agreement: *the number of* → singular; *a number of* → plural; *each of* → singular; *neither A nor B* → verb agrees with B.
- Analogies: say the relation as a sentence ("A cartographer **makes** a map") and keep the **order**.
- Two-blank contrast: decide the polarity (+ / −) of each blank first, then pick words.
- Phrasal verbs change meaning with the particle: *cover up* (hide), *cover for* (stand in), *play up* (exaggerate), *make up* (invent).

## Shortcuts
| Clue | Expect |
|---|---|
| although / but / yet | blanks of opposite polarity |
| and / moreover | same polarity |
| without discussion, at once | summarily, promptly |
| silent h / letter names (M, S, X) | *an* |
| "yoo" / "w" sound (u, eu, one) | *a* |

## Traps
1. **Sound-alike words** (summarily vs sumptuously, ephemeral vs ethereal). Fix: define the option in your own words before matching.
2. **Article by letter.** Fix: say the word aloud; *honest* starts with a vowel sound, *useful* with a "y" sound.
3. **since vs for.** Fix: if you can put "how long?" in front, use *for*; "from when?" → *since*.
4. **Reversed analogy direction** (Symphony : Composer for Cartographer : Map). Fix: test the exact sentence in the same order.
5. **Synonym chosen for an antonym question.** Fix: underline OPPOSITE in the stem.
6. **Agreeing with the nearest noun** (*Each of the reports have*). Fix: find the true subject first.
7. **Missing the contrast word.** Fix: mark *although/but* and set blank polarities before reading options.

## Recall
- Article by first **sound**: an hour, an MBA, a European, a useful.
- for + duration; since + starting point.
- assure people, ensure outcomes, insure property.
- affect = verb, effect = noun (usually).
- The number of → singular; a number of → plural.
- Neither A nor B → verb agrees with B.
- Analogy: relation sentence + same order.
- summarily = at once, without formality; sumptuously = lavishly.
